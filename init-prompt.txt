I want to build an app for studying song lyrics. The v1 will focus on an English speaker learning Japanese words, context, and perhaps grammer through song lyrics. Using the app, I would like the user to be able to search for a song. Once selected, the app will show the lyrics. Be sure to include furigana for any kanji. When the user highlights a word, I want to display a translation of that word, the meaning of the full sentence/phrase in which it was used, the place(s) in the song where the word was used (for human consumption - line number and place is less useful here), and other words that use that kanji. I also want a separate tab or view that shows the list of words used in the song. For that view, I want the highlight behavior to be the same - ie - use the same component

I want the stack to be React/TypeScript on the frontend, a Python backend, and a NoSQL DB such as DynamoDB. Have a basic user login system. Save songs that have been previously analyzed. Allow users to keep a history on songs that have been analyzed. Use the same song analysis when other users select the same song
